# テトリス

C言語で書かれたターミナル上で動作するテトリスです。ANSI エスケープシーケンスに対応した端末で動作し、10×22 のカラー盤面、着地点を示すゴーストピース、次と次の次のテトリミノのプレビューを表示します。ハイスコアはファイルに保存されます。

## 必要環境

- GCC（または任意のCコンパイラ）
- GNU Make
- POSIX 環境（`unistd.h`、`select`、`fcntl`、`stty`）
- ANSI エスケープシーケンスに対応した端末

## ビルド

```sh
make
```

`bin/tetris` に実行ファイルが生成されます。

ビルド成果物を削除するには:

```sh
make clean
```

## 実行

```sh
./bin/tetris
```

ゲーム開始時に画面をクリアし、Enter キーを待たずにキー入力を受け付けるため端末を raw モードに切り替えます。終了時には cooked モードに戻します。

## 操作方法

| キー  | 動作                |
| ---- | ------------------- |
| `a`  | 左に移動            |
| `d`  | 右に移動            |
| `x`  | ソフトドロップ       |
| `s`  | ハードドロップ       |
| `q`  | 時計回りに回転       |
| `e`  | 反時計回りに回転     |
| `z`  | ゲームオーバーへ     |

ゲームオーバー画面では:

| キー  | 動作       |
| ---- | ---------- |
| `w`  | リプレイ    |
| `q`  | 終了       |

## スコア

一度に消したライン数に応じて得点が入ります:

| 消去ライン数 | スコア |
| ----------- | ------ |
| 1           | 100    |
| 2           | 300    |
| 3           | 500    |
| 4           | 800    |

最高得点は `data/high_score` に保存され、ゲームオーバー画面に表示されます。

## ディレクトリ構成

```
tetris/
├── Makefile
├── bin/           # ビルド成果物（tetris 実行ファイル）
├── data/
│   └── high_score # 保存されたハイスコア
├── include/
│   ├── score.h
│   └── tetrimino.h
└── src/
    ├── tetris.c     # メインループ、描画、入力処理
    ├── tetrimino.c  # テトリミノの生成・移動・回転・ライン消去
    └── score.c      # ハイスコアの読み書き
```
